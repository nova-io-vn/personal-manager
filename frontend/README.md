# Personal Manager frontend

React + TypeScript + Vite frontend for the local-first Personal Manager application.

Implemented routes include Dashboard, Finance, weekly Calendar, Health/Nutrition, Journal, Gemini Assistant, and Settings. The application shell includes a persisted in-app notification center. All visible data is loaded from the local FastAPI API.

## Run

```bash
npm install
npm run dev
```

The development UI runs at http://localhost:5173. Copy `.env.example` to `.env` to override the backend URL with `VITE_API_BASE_URL`.

## Verify

```bash
npm run lint
npm run build
npm run test:e2e
```

The frontend expects the FastAPI backend at http://127.0.0.1:8000/api by default. Playwright E2E starts local servers and a unique temporary database, then terminates the server trees; it never targets `backend/data/personal.db`.

Production builds use relative asset paths so Electron can load the UI from `file://`. Electron provides the dynamically selected loopback API URL through its isolated preload; browser development uses `VITE_API_BASE_URL`.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
